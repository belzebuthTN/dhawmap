# Dhawmap (Vite)

Projet Vite + React pour le composant `DhawmapLive`.

Commandes:

```bash
cd dhawmap
npm install
npm run dev       # développement
npm run build     # build production (dist/)
npm run preview   # aperçu de la build
```

Déploiement recommandé: Vercel (connecter le repo GitHub ou utiliser `vercel` CLI).
